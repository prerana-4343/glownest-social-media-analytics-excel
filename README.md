# GlowNest Social Media Analytics | Excel Project

## Project Overview
This project analyzes social media performance for GlowNest, a lifestyle brand, using Microsoft Excel. The analysis focuses on identifying which social media platforms, content formats, and content themes generate meaningful audience engagement and link clicks.

## Business Problem
GlowNest publishes content across Instagram, Facebook, and LinkedIn. The marketing team wants to understand whether high reach translates into meaningful engagement and audience action.

The objective is to compare platform effectiveness and content performance to support data-driven marketing decisions.

## Dataset
- **Total records:** 600 social media posts
- **Time period:** January–December 2025
- **Platforms:** Instagram, Facebook, LinkedIn
- **Source:** Provided Excel dataset

## Tools Used
- Microsoft Excel
- Data Cleaning
- Excel Formulas
- KPI Analysis
- Data Visualization
- Data Quality Validation

## Project Objectives
- Analyze reach, impressions, engagements, and link clicks.
- Compare performance across social media platforms.
- Evaluate content formats such as short videos, carousels, static images, and text/articles.
- Compare engagement across different content themes.
- Identify missing values, inconsistent labels, and duplicate Post IDs.
- Develop evidence-based marketing recommendations.

## Key Performance Indicators
- Total Reach
- Total Impressions
- Total Engagements
- Engagement Rate
- Total Link Clicks
- Link Click Rate
- Total Saves

## Data Cleaning
- Standardized inconsistent platform and content-type labels.
- Reviewed missing campaign and engagement metric values.
- Flagged repeated Post IDs for further investigation.
- Calculated engagement rate using total engagements divided by total reach.
- Calculated link click rate using total link clicks divided by total reach.

## Analysis Performed
1. **Platform Analysis:** Compared reach, engagement, and link clicks across platforms.
2. **Content Format Analysis:** Evaluated performance across different content formats.
3. **Content Theme Analysis:** Compared educational content, product promotions, and other themes.
4. **Monthly Trend Analysis:** Reviewed social media performance over time.
5. **Data Quality Review:** Documented missing values and potential duplicate records.

## Business Value
This project demonstrates how Excel can be used to organize, analyze, and summarize social media data to support marketing decisions and improve content planning.

## Limitations
Missing values were not automatically treated as zero. Repeated Post IDs were flagged for review rather than automatically deleted. Performance differences indicate associations and do not establish causation.
